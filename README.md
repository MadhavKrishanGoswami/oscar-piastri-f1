# 🏎️ Oscar Piastri F1 Dashboard

An unofficial fan dashboard tracking Oscar Piastri's Formula 1 journey — race results, career stats, championship standings, and more.

![Oscar Piastri](https://img.shields.io/badge/Driver-Oscar%20Piastri-FF8000?style=for-the-badge)
![Team](https://img.shields.io/badge/Team-McLaren-0055FF?style=for-the-badge)
![Number](https://img.shields.io/badge/Number-81-FF8000?style=for-the-badge)

## 🏁 Features

- **Hero Section**: Dramatic intro with driver number and key stats
- **Career Statistics**: Comprehensive stats cards showing wins, podiums, points
- **2024 Season Results**: Race-by-race breakdown with finishing positions
- **Visual Charts**: Interactive area chart showing race positions throughout the season
- **Teammate Battle**: Head-to-head comparison with Lando Norris
- **Career Timeline**: Journey from karting to Formula 1
- **2025 Calendar**: Upcoming races with home race highlight

## 🎨 Design Philosophy

The design captures Oscar's personality and McLaren heritage:
- **Dark theme** — sleek and technical like F1 engineering
- **Papaya Orange** — McLaren's iconic color
- **Sharp geometric elements** — inspired by F1 car aerodynamics
- **Smooth animations** — the speed and precision of racing
- **Australian touches** — subtle nods to his heritage

## 🛠️ Tech Stack

- **Next.js 14** — React framework
- **TypeScript** — Type safety
- **Tailwind CSS** — Styling
- **Framer Motion** — Animations
- **Recharts** — Data visualization
- **Lucide React** — Icons

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/MadhavKrishanGoswami/oscar-piastri-f1.git

# Install dependencies
cd oscar-piastri-f1
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

## 📊 Data Sources

All statistics are compiled from official Formula 1 data and represent Oscar Piastri's career through the 2024 season.
